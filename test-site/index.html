We sell sourdough. This page has nothing to do with the widget platform's codebase — it's served from a completely different origin (a second local port) to prove the embed actually works cross-origin.

Serve this file from a different origin than the API, e.g.:
npx serve test-site -l 5500 or python3 -m http.server 5500 --directory test-site
then open http://localhost:5500 — that's origin #2, talking to the API on origin #1 (port 3000).
